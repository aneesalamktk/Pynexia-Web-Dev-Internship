# Week 2 — Wedding Planner Website

A responsive portfolio website for a fictional wedding and commercial event-planning studio, **Aster & Ivy Events**.

## Features
- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Sections for profile/story, services, selected projects, skills, experience, education, and contact
- Contact form with required-field and email validation
- Form prepares an enquiry in the visitor's email app using `mailto:`
- Current year automatically displayed in the footer
- Accessible labels and status messages

## Technologies
- HTML5
- CSS3
- JavaScript (DOM manipulation and form handling)

## Run the project
1. Open this `Week-2` folder in Visual Studio Code.
2. Open `index.html` in your browser, or use the Live Server extension.
3. Internet access is needed for the Google Fonts and remote Unsplash photos.

No npm packages or build tools are required.

## Customize before submitting
- Replace the sample name, profile, experience, education, email, and location with your own details.
- The project names and visuals are sample portfolio content.
- Replace `hello@asterandivy.example` in `index.html` and `script.js` with an email address you control if you want the form to open a real email draft.
- The contact form does not submit to a server or save messages; it only opens the visitor's email app.
- Images are loaded from Unsplash URLs and need internet access.

## Folder contents
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and contact form behavior
