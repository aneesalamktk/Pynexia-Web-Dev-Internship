# Pynexi Task Manager

A simple task management web application built for an internship task using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- View the task list
- Edit existing tasks
- Mark tasks as completed or pending
- Delete tasks
- Filter all, pending, and completed tasks
- Show total, pending, and completed task counts
- Save and retrieve tasks with browser `localStorage`
- Responsive layout for smaller screens

## How to run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add a task using the form.

No Node.js packages or database are required.

## Technologies

- HTML
- CSS
- JavaScript
- DOM manipulation and event handling
- `window.localStorage`

## Storage note

Tasks are saved in the browser where the application is used. They are not synced between different browsers or devices.
